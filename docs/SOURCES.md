## Data Handling Rules

1. Preserve original downloaded files.
2. Do not modify files inside datasets/raw.
3. Record the download date and source URL.
4. Keep processed datasets separate from raw datasets.
5. Do not claim that incomplete data represents all India.
6. Clearly identify synthetic or demonstration datasets.
