# NIRIKSHAN AI – Data Dictionary

> IMPORTANT: This document does NOT contain official MPLADS column names or
> statistics. Official field names must be confirmed by inspecting the actual
> files from official sources. Items marked **TBD** are intentionally unfilled.

## 1. How to Use This Document

There are two kinds of fields:

- **Source fields**: columns in official MPLADS data. Their real names, types
  and formats are **unknown until you download and inspect the data**.
- **Internal fields**: names WE define for our own database and pipeline.
  Source fields are mapped onto these during ingestion.

Workflow: download official data → list its real columns → fill the mapping
table in Section 5 → write the ingestion mapping.

## 2. Real vs Synthetic Data

| Aspect | Real data | Synthetic data |
|--------|-----------|----------------|
| Location | `datasets/raw/`, `datasets/processed/` | `datasets/synthetic/` |
| Origin | Official government sources | Generated by `ml/synthetic.py` |
| `data_origin` value | `real` | `synthetic` |
| Valid for | Actual analysis | Building, testing, demos only |
| Names | Real entities | Fake IDs only (e.g. `SYN-MP-001`) |
| UI treatment | Normal | Persistent "DEMONSTRATION DATA" banner |

Rules for synthetic data:
1. Never use real MP, constituency or district names.
2. Never imitate real statistics or claim realism.
3. Generated with a fixed random seed so results are reproducible.
4. Includes a few deliberately injected outliers, stored in a hidden
   `injected_anomaly` column, used only to test the models.

## 3. Data That Must Be Obtained From Official Sources

Check which of these official sources publish what you need. Do not assume
availability; verify each one.

| Source | What to look for |
|--------|------------------|
| MPLADS official website (Ministry of Statistics and Programme Implementation) | Fund release and expenditure reports, project listings, guidelines |
| Open Government Data Platform India (data.gov.in) | Any MPLADS-related datasets and their licences |
| Lok Sabha / Rajya Sabha official websites | MP lists, constituency and term information |
| Official MPLADS guidelines document | Rules about limits, installments and allowed work types (needed to interpret features correctly) |

Record for every file you download: source URL, download date, licence or
terms of use, and the reporting period it covers. Store this in
`docs/SOURCES.md`.

## 6. Internal Database Tables (our design)

### `datasets`
| Field | Type | Description |
|-------|------|-------------|
| `id` | integer PK | Dataset ID |
| `name` | text | Human-readable name |
| `data_origin` | text | `real` or `synthetic` |
| `source_note` | text | URL or description of origin |
| `period_covered` | text | Reporting period description |
| `ingested_at` | datetime | When loaded |
| `row_count` | integer | Rows loaded |

### `records`
| Field | Type | Description |
|-------|------|-------------|
| `id` | integer PK | Record ID |
| `dataset_id` | integer FK | Parent dataset |
| `entity_id` | text | MP or other unit of analysis (internal) |
| `period` | text | Reporting period |
| `payload_json` | text | Cleaned source values as JSON, so the schema can change without migrations |

### `features`
| Field | Type | Description |
|-------|------|-------------|
| `record_id` | integer FK | Link to record |
| `run_id` | integer FK | Which run generated it |
| `feature_json` | text | Engineered feature values |

### `model_runs`
| Field | Type | Description |
|-------|------|-------------|
| `id` | integer PK | Run ID |
| `dataset_id` | integer FK | Dataset analysed |
| `started_at` / `finished_at` | datetime | Timing |
| `status` | text | `pending`, `running`, `done`, `failed` |
| `params_json` | text | Model parameters, random seed, feature list |
| `data_origin` | text | Copied from the dataset |

### `anomaly_scores`
| Field | Type | Description |
|-------|------|-------------|
| `run_id` | integer FK | Run |
| `record_id` | integer FK | Record |
| `iforest_score` | real | Normalised 0–1, higher = more unusual |
| `lof_score` | real | Normalised 0–1, higher = more unusual |
| `combined_score` | real | Average of the two |
| `is_flagged` | integer | 1 if above threshold |
| `explanation_json` | text | Top deviating features |
| `pca_x`, `pca_y` | real | 2-D coordinates for plotting |

## 7. Candidate Engineered Features (design ideas)

Computed only if the needed source concepts exist.

| Feature | Formula (conceptual) | Intuition |
|---------|----------------------|-----------|
| `utilisation_ratio` | spent ÷ released | How much of the released money was spent |
| `sanction_ratio` | sanctioned ÷ released | Commitment relative to release |
| `completion_ratio` | completed ÷ sanctioned (project counts) | Execution rate |
| `avg_project_size` | sanctioned amount ÷ projects sanctioned | Typical project scale |
| `duration_days` | completion date − sanction date | Execution speed |

Division by zero must be handled explicitly (result = missing, not infinity).
